# 简洁主题

中央使用生图生成的 CPU 芯片，进程节点直接显示应用图标。桌面端优先提取可执行文件图标，无法取得图标时使用已有品牌图标或名称缩写。节点结束时淡出收缩。

唯一需要制作的图片是 `public/assets/generated/refined/minimal/core.png`，提示词和来源见同目录 `PROMPT.md`。纯黑底由加载器去除。自定义主题继承 minimal 时仅需核心素材，背景、环境、生物图集、Agent 和捕获素材均不加载；连接线、型号文字及占用率由程序绘制。

桌面实时采样通过 sysinfo 的 CPU brand 读取真实型号，以 `cpuModel` 字段传给中央芯片。界面清理商标标记并自动换行，保留型号本身。浏览器演示或型号不可用时显示 CPU，不伪造硬件数据。
