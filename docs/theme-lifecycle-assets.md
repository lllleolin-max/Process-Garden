# 主题素材与回收动作契约

入口：设置 → 主题 → 创建自定义主题。选择「回收动作」，展开「AI 素材与自定义图片」查看清单、复制整套提示词、上传 PNG，然后保存和导出 `.pgtheme`。

完整新主题含可选变体需要 **11 张 PNG**；深海克苏鲁和猩红凝视另外需要吞噬核心，共 **12 张**。图集 3、4 是可选的额外变体；不制作时主体套装为 9 张或 10 张。允许只替换部分素材，空槽继承基础主题。

槽位约定的是功能，不是固定物种：花园使用植物与种子，深海使用触手与海怪，霓虹使用无人机、算力装置与装配舱，猩红使用眼眷、眼睑成长和瞳孔吞噬。制作新主题应独立设计轮廓、材质和成长过程，无需把相同生物换色。当前四套生图结果与逐张提示词见 [生成记录](../public/assets/generated/refined/GENERATION.json)。`crimson` 可作为自定义主题的 `basedOn`，默认使用带眼睛的触手部件。

## 统一动作接口

`captureStyle` 支持 `vine`（枝桠汲养）、`tentacle`（触手）、`cable`（缆索）和 `beam`（接引光束）。garden 默认 vine，eldritch/crimson 默认 tentacle，cyberpunk 默认 beam，允许跨主题选择。v2 manifest 可仅声明此参数，也可同时提供 `assets.capture`。后者与其他素材一样使用 `assets/<sha256>.png`，随主题包导入导出。

beam 复用 capture 上传槽：左上水平光柱、右上接触辉光、左下投射口、右下空心锁定光环；程序驱动投射、锁定、引导回港和消散，共用动作时序。缺省素材可继承，提供自定义 capture 时必须制作这四格。生成记录见 [BEAM-PROMPT.md](../public/assets/generated/lifecycle/BEAM-PROMPT.md)。

四个部件必须有一致的材质、光向与粗细。直杆保持水平方向；末端朝右；缠绕环中央留空。不要把整根附肢烘焙到核心或进程生物里，也无需手工制作一张张完整退出帧。

程序共用退出时钟，按模块驱动不同姿态：花园伸枝汲养后原地枯萎，触手捕获吞噬，光束锁定回港。触手与光束在确认前提供捕获预览，移开或取消会解除；花园确认前不枯萎。进程自然退出复用所选退场动作；搜索、筛选或生态聚合隐藏仍在运行的进程不触发真实退场。减少动态效果时直接呈现交互状态。

素材必须使用生图模型精美设计，代码只负责贴图变形、透明度、轨迹和前后遮挡。根目录 [AGENTS.md](../AGENTS.md) 定义了项目规则。内置三套回收图的原始提示词见 [生成记录](../public/assets/generated/lifecycle/PROMPTS.md)。实际生成图尺寸以 PNG 为准；建议尺寸不是模型输出保证。

新增素材角色时，同步更新 `themeAssetRoles`、schema、加载器、`assetSpecs`、上传入口和提示词，不应为每个新主题复制整套 Canvas 生命周期代码。

## 按主题退场（2026-09-16）

- garden / vine：核心先伸出带叶枝桠接触进程，养分沿枝桠回流；吸收后进程在原位置褪色、弯折、下沉，碎屑归土。复用已生成的 vine 四格素材，确认前不伸枝吸收。
- eldritch / tentacle：保留触手捕获、吞噬、咬合与核心反冲。
- cyberpunk / beam：投射已有生成光束，锁定后沿引导路径返回核心基地，入港时缩小消隐；无吞噬旋涡。
- 自定义 cable：保留机械牵引。

主进程与 Agent 子进程使用相同主题退场姿态。确认前不触发枯萎；取消不会结束进程。搜索或聚合隐藏的存活进程仅淡出。暂停、减少动态效果与现有场景时钟保持一致。复用已生成的生物与 vine/beam/tentacle 图集，不新增图片槽。
