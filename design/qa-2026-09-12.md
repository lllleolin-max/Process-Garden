Historical verification of the earlier motion-only build. The current combined release is documented in [the unified QA record](qa-unified-2026-09-12.md); the results below remain evidence for their stated source version.

## Implemented and verified

- Canvas scheduling sleeps while paused, hidden or in reduced motion. Data and asset updates wake static rendering. Stable node spacing, focus label ordering and PID-based motion preserve process identity.
- Paused search removes unmatched organisms immediately; paused resizing recomputes positions. Escape bubbles from the focused Canvas to the application in fullscreen and wallpaper modes.
- Charts interpolate through interrupted samples; memory bars use scale transforms. Compact 1040×720 desktop panels show all four metrics and uptime. The 390×844 browser layout keeps search, dock and timeline usable.
- Settings and theme surfaces animate on entry and exit, trap focus, make the background inert and return focus to the trigger. Keyboard tabs, switch semantics, search clearing, clipboard errors and theme import/name conflicts have behavior coverage.
- All display-mode entry points share one ordered transaction. A later Escape cancels pending entry, preventing an obsolete promise from putting the app back into wallpaper. Browser fullscreen exit and native restoration use the same state path.
- Sampling cannot overlap or publish stale results after pause, hiding or reconfiguration. Icon requests survive sampling rerenders, retry failures and avoid redundant notifications. Collector changes clear mixed histories.
- Native process sampling runs in a blocking worker instead of the UI thread. Worker clones share one collector lock and CPU baseline. This fixes a main-thread blocking path discovered during packaged-executable smoke testing.
- Generated celestial alpha is preserved; the generated maw v3 replaces obsolete triangle teeth. The rejected v2 draft was moved outside `public/` to a local ignored draft directory so Vite cannot package it.
- The generated maw's black matte is converted to alpha at image load and cached. This removes the rectangular edge during the open-mouth phase over transparent Canvas pixels. Existing source transparency and the celestial preserve-alpha path remain intact. The change was backported independently from later ambient/embryo features and reviewed for pause, reduced-motion and unmount safety.

## Evidence

- TypeScript build check passed.
- Full frontend suite: **90 tests across 20 files passed** after the maw transparency backport. Local migration backups are excluded from test discovery; the original backup files are retained.
- Production frontend build passed before packaging; the Tauri build regenerates it for the final source.
- Rust: **5/5 tests passed** with `cargo test --lib --locked --offline`; `cargo check --locked --offline` passed without warnings after the native sampling fix. Combined final native verification took 72 seconds using the existing toolchain/cache.
- Browser checks: Garden and Eldritch imagery, theme and language switching, 1040×720 desktop and 390×844 narrow viewports, focus return, reduced motion, pause consistency, 30/60/120 Hz selected states, fullscreen and wallpaper entry/exit. Garden wallpaper visibly displays the generated sun at the current local daytime.
- Interactive QA caught a focused-Canvas Escape conflict after the first packaging run. It was fixed, covered with two tests and rebuilt; do not use the earlier intermediate binaries.
- Native QA then caught intermittent window non-response (responsive at 8/16 seconds, unresponsive at 24/32/40 seconds). The synchronous sampling command ran on the UI thread; `1621914` moves it to `spawn_blocking`. This follows both the local Tauri macro implementation and the [Tauri command threading documentation](https://v2.tauri.app/develop/calling-rust/).
- The rebuilt portable executable passed a **40-second native responsiveness smoke**: alive, nonzero window handle and `Responding=true` at 8/16/24/32/40 seconds. The checker then stopped only its own launched process. Packaging uses that verified release executable.
