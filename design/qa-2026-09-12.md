- Paused search removes unmatched organisms immediately; paused resizing recomputes positions. Escape bubbles from the focused Canvas to the application in fullscreen and wallpaper modes.
- Charts interpolate through interrupted samples; memory bars use scale transforms. Compact 1040×720 desktop panels show all four metrics and uptime. The 390×844 browser layout keeps search, dock and timeline usable.
- Settings and theme surfaces animate on entry and exit, trap focus, make the background inert and return focus to the trigger. Keyboard tabs, switch semantics, search clearing, clipboard errors and theme import/name conflicts have behavior coverage.
